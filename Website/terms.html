🔐 2. Description du service

CourrierCode est une application de chiffrement de messages utilisant un système de codage par substitution de lettres. L'application permet :

  • L'encodage de messages texte
  • Le décodage de messages chiffrés
  • La gestion d'un carnet de correspondants (stocké localement)
  • L'encodage d'images (fonctionnalité Premium)
